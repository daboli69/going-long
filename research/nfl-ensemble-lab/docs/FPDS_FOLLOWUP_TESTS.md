# Six follow-up tests (Amendment9)

Run locally with `scripts\launchers\run_fpds_followups.bat`. The command uses Idle priority and leaves two logical cores free. The default budget is two hours. Inspect `scripts\launchers\run_fpds_followups.bat status`; resume an incomplete frozen snapshot with `scripts\launchers\run_fpds_followups.bat resume --run RUN_ID --hours 2`. Completed studies cannot be overwritten. Failed blocks are retained and skipped; their family cannot qualify. Stop with Ctrl+C and retain the checkpoint.

The committed `FPDS_A9_PROTOCOL.json` fixes every formula, split, metric and threshold before fits. These are already examined 2022–2024 discovery seasons, not a new holdout. The program does not refresh providers, run the spent props evaluation, score 2025/2026, change the champion or write forecasts.

1. Target audit compares regulation with overtime-inclusive local PBP, using the existing observation aggregator on a temporary in-memory quarter mapping. It also counts exact player/game/team observation mismatches. It does not invent IDs or replace old targets. Kneels/spikes remain excluded, so this is not official box-score or bookmaker-settlement validation.
2. Matched NFL-only receiving/rushing quantiles use the identical saved FPDS model specifications. Comparing these controls with FPDS isolates provider value; comparing with the old equal ensemble measures the objective/model-family change. No FPDS models are refitted.
3. Three conservative FPDS residual corrections use earlier emitted out-of-fold errors only, Ridge alpha100 and fixed50% shrinkage. The exact saved champion test is blocked: its calibration method was selected using later examined seasons. The strictly chronological richer NFL baseline is explicitly a surrogate, not the production champion. No saved champion weights are altered.
4. Soft reconciliation blends25% toward the repaired opportunity models for six props and both arms. Other-player mass stays in the saved hierarchy diagnostics; partial adjustment does not imply exact coherence. Distinct-scorer probabilities are not TD-event counts.
5. Earlier-only expanding conformal corrections widen saved receiving/rushing intervals, retaining their medians. Empirical coverage, width and interval score are reported; no exchangeability guarantee is claimed for changing NFL seasons.
6. Prior shrinkage and exact binned Brier decomposition diagnose probability errors for winners and anytime TD. The decomposition includes a within-bin residual, avoiding the false exactness of a coarse-bin reliability/resolution formula. AUC, accuracy and log loss are secondary; Brier remains primary.

All source hashes are checked before and after. Fitted outputs, raw PBP extracts, player keys and row-level predictions remain ignored in `data/cache/fpds/amendment6/followup9/`.
