# FantasyPoints metrics in the simulated game: what was tested

Generated by `scripts/fpds_usage_check.py`. Fitted on 2022 to 2024, scored on 2025 and on 2026 so far (weeks 3 to 7) using only weeks before each game. Aggregate numbers only; no FantasyPoints rows are published.

FantasyPoints weekly rows reach week 7 of 2026. A full week lists about 303 players with a target share; the weeks that list fewer (week 5: 92, week 6: 94) are used as they are. A player's average covers the weeks he has rows for. Partial weeks lean toward busier players, so a player who appears only in a partial week can look busier than he is.

Blend weights, fitted on 2022 to 2024:

- Receiving yards: 40% nflverse share, 50% target share, 10% air yards share, for everyone expected to play. Passed the gate and is used.
- Catches: 60% nflverse share, 10% target share, 30% routes run, for everyone expected to play. Passed the gate and is used.
- Rushing yards: no blend passed the gate (both years must show a gain with the whole interval below zero), so the nflverse share is used.

The narrower group (thin history only) is used for a stat only when the broader group fails the gate, so it shows "no" when everyone already passed.

Players outside the chosen group keep the nflverse share. Historical weeks were exported in 2026, so they are each week's final values rather than what was posted at the time; target and route counts rarely change, but this is a limit of the test.

## Not tested, so not used

- FantasyPoints stuff rate: it averages about 47% against about 17% for carries that gain 0 or fewer yards, so the definition differs. The data dictionary also calls header definitions unverified.
- Pass-and-run tendencies by game state: nflverse play-by-play gives the same numbers, so FantasyPoints adds nothing new to test.
- Rushing volume from carry share and snap share: no gain that held in both years.
