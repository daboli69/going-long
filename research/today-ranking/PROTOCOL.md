# Today ranking experiment v1 — preregistered, no promotion

Purpose: compare research attention allocated by probability-first Champion, C1 theoretical-return order and C2 family-diversified C1 on future frozen slates. No odds/model/production ranking change. GOING Score is not probability and is not a factor. Registration is `experiment-v1.json`; committed source, hashes and this protocol precede prospective collection. Original research remains a descriptive October 2 snapshot, not a retrospectively reconstructed backtest.

## Frozen policies and universes

Champion v1 is actual `rankBestPlays` plus first-visit `filterBestPlays`: sport/type, ET Tuesday–Monday week, future kickoff, valid nonfuture quotes <=24h, finite 0<p<1, n>=5 recorded games, no blocking check except historical-only. Existing generation removes manual/DFS/unmatched/unpriced inputs. Sort probability DESC then original push-aware EV DESC; stable source order for exact ties. Exact canonical-contract book dedup follows sort. Prop alternate primary = closest decimal1.91; hide other prop lines, not game alternates; American odds >=-500; no user/book/query/focus restriction. Default page is weekly. Saved user filters are NOT part of the systematic experiment. Game cards follow their leading entry; full ranked list is the primary rank unit, not number of cards seen. Exact source hashes are registered; any policy/generator change stops collection until an explicitly new preregistered version. Input vintages change legitimately and are individually pinned.

C1 v1 preserves October 2 implementation byte-for-byte: on the identical ordered Champion-eligible pool, sort `pWin*decimal+pPush-1` DESC; exact ties retain Champion input order. Unconditional pWin/pPush; absent push follows the source zero-push approximation. No fitted weights or price/probability alterations.

C2 v1 preserves the same implementation: walk C1 order, retaining FIRST row per exact `[event,kind,profileId-or-game,market,side]`. Ignore line/book only for this research-attention grouping; do not alias different kickoff clocks or market directions. Representative is therefore highest estimated return, then Champion tie order, fixed BEFORE outcomes. Different thresholds remain different settlement contracts; family grouping does not prove correlation or independence. Both Challengers stay offline.

Store four sport/type cohorts (NFL combined/props/games; NCAA games), weekly plus Today(ET) complete ranks and top3/top10. Additionally preregister Today-settleable views for full-game spread/total/ML and supported NFL yards/receptions/TD contracts. FirstTD/period outcomes cannot be trusted from current full-game results: retain them in full original pools/ranks, explicitly unresolved, and exclude them from the SAME confirmatory universe for ALL policies before ranking. Restricted-universe conclusions cannot justify unrestricted Today promotion. NCAA props are never introduced.

## Timing and persistence

Existing eight America/New_York Codex occurrences collect a snapshot at cycle start, before choosing a development task, from freshly fetched public origin/main files and the exact source checkout. Capture uses actual process time; CLI provides NO backdate/replay switch, no provider/network calls and no browser-local/user-choice cohort. Snapshot window is requested local hour through minute15. One immutable experiment+ETdate+slot observation; later retries retain the original rather than recompute it. A manual setup capture is labelled manual and excluded from confirmatory evaluation.

Primary sample is scheduled 08:00–08:15 ET, October3–December5 inclusive, Today-settleable. This avoids changing time selection after outcomes and DST's ambiguous/missing 02:00 hour. Missing primary slots stay missing; no later catchup. Other seven slots/weekly views are exploratory, never substitutions for failed primary observations. Quotes >5m remain marked saved research, not actionable/positive value; report freshness strata and missingness. No games is a valid zero-eligible observation, not evidence of failure/success.

Persist in `docs/ranking-observations/today-ranking-v1/YYYY-MM-DD/` on ONLY the automation-owned review branch. Lossless columnar pool/evidence/exclusion chunks, content-addressed gzip records and final snapshot manifests keep complete pools reproducible without repeating enormous objects. All source input blobs are pinned by Git commit+SHA256; unsupported/unparsed raw markets are auditable there and are not fabricated modeled candidates. Frozen rows contain exact contract/game/player/source/market/direction/line/book/price/quote time, model probability/push/return/sample/profile date, evidence summary/freshness, directional family, every eligibility/exclusion and Champion/C1/C2 full ranks/topN. Derived quote age/frozenAt come ONLY from immutable original timestamps, never from evaluation time. Capture rechecks input hashes after calculation.

Text provenance hashes use UTF-8 with ONLY CRLF normalized to LF, matching Git's text blobs across Windows/Linux checkouts; all other whitespace and data values remain significant. Canonical journal bytes and Git preservation hashes are exact bytes, never whitespace-normalized. This distinction was frozen before the first real observation and does not alter predictions, C1/C2 or eligibility.

The journal uses canonical JSON SHA256, sequence/previous hash, immutable logical keys, exclusive writer lock, fsynced temporary bytes and atomic no-overwrite publication. Partial/corrupt/unknown files or a lock fail closed; no automatic stale takeover/deletion. Snapshot manifest is written LAST and must reference every required chunk. Unreferenced chunks from an interrupted capture are not a completed observation. Daily segmentation bounds scans; per-record1MiB, total256MiB/day limits stop rather than truncate. Before capture, settlement and verification, `preservation.cjs` requires the review branch and compares EVERY published journal blob/mode to both index and working bytes: tail deletion, replacement and staged tampering fail even if a shorter hash chain is internally valid. Publication also preserves prior blobs/modes. Invalidation is a new immutable reason/evidence record referencing the original snapshot. No cryptographic protection against a malicious administrator rewriting all history is claimed.

## Outcomes and uncertainty

Append result evidence independently using already published `data/results.json`; never rerun predictions for old outcomes. Exact sport/team/day matchup must uniquely match; official kickoff must follow freeze. Completed full-game public results with postkick source timestamps/hash and observed player metric grade win/loss/push. Negative yards are legitimate. Missing player participation is NOT zero/automatic void; ambiguous/conflicting identity, unsupported FirstTD/period/SGP/book exceptions, missing/stale source and partial evidence remain unresolved. A changed result creates a conflicting append, excludes that prediction from automatic analysis and requires an auditable integrity decision. It never replaces the first result. Settlements are statistical research grading, not claims about sportsbook execution/void rules. Invalidation requires reason, evidence reference and target snapshot; record remains preserved.

Diagnostic collection: October3–23. Untouched confirmation: October24–December5. No fitting/weight tuning on either interval in v1. Do not read aggregate holdout accuracy/performance until December6 12:00 ET; collection/identity/integrity checks may inspect raw evidence only as needed. Evaluation CLI refuses early release; new hypotheses require new version and future start. Never change these cutoffs/policies/thresholds in place after collection.

For each primary league/universe/N=3,10: identical captured eligible pool for all policies, fixed frozen topN, no replacing missing/losing selections. Report total slates/contracts/unique games/players/families, settled/push/unresolved/reference-missing counts and coverage. Probability scoring on settled nonpush rows uses pWin/(1-pPush); compare only genuine frozen same-book two-sided references, normalized conditional on nonpush. Brier/log loss and reliability are required; raw Brier across policies selecting different base rates cannot alone prove bet value. Primary statistic is model-minus-reference Brier at selected topN, then paired Challenger-minus-Champion by slate; negative means improved relative probability scoring, not profitability. Report game-balanced and slate-balanced diagnostics, composition/price/EV/freshness, family/game concentration and all limitations. Never treat correlated alternate/player/game legs or eight snapshots/day as independent. Only primary one/day enters confirmation; uncertainty resamples ET slate-date clusters (retaining all games/markets within date), 2,000 deterministic bootstrap draws. Game-cluster diagnostics are secondary. Preserve shared-date dependence between sports in any combined exploratory output.

Minimum per comparison:20 paired primary slates,100 unique game clusters, <=10% unresolved and <=10% missing paired-reference coverage. Otherwise INSUFFICIENT, no superiority claim. Report complete-case matched-reference subset and attrition explicitly; selection/availability bias remains. Eight predeclared comparisons (two Challengers x two leagues x top3/top10); Bonferroni two-sided familywise5% intervals plus unadjusted95% diagnostic intervals. Candidate evidence requires adjusted interval below zero, at least .005 excess-Brier improvement and no mean log-loss deterioration >.01 on paired references. These are prospective practical screening thresholds, not empirical proof of optimal ranking. Passing does NOT promote; reproducibility, calibration/reliability/sample/coverage/regression review and explicit Travis approval remain required.

This fixed pilot may not meet those requirements: football does not have 20 independent game-days per league in every six-week window, top3 can cover too few games, and ATD often lacks a frozen two-sided reference. Zero-game primary slots do not manufacture sample size. If the pilot is insufficient, report it; do not lower thresholds, extend cutoffs or consume the holdout to tune v1. Any follow-on study must preregister a new future cohort/version before its outcomes.

No realized ROI/CLV in v1. Frozen prices enable later quoted-price diagnostics only after verified settlement/execution/void handling; this protocol does not establish it. Later scheduled quotes are not automatically closes. No historical price reconstruction, invented odds, Score/100, hit-rate-only or profitability claim. No universal model/evidence composite is invented.

Method references: [Gneiting & Raftery, proper probability scoring rules](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf) supports Brier/logarithmic scoring; [Stata's cluster bootstrap documentation](https://www.stata.com/support/faqs/statistics/bootstrap-with-panel-data/) explains preserving dependent groups when resampling. Neither establishes Going Long accuracy. Date clusters preserve same-slate dependence, but recurring teams/players and a short season can leave cross-date dependence; report this limitation and do not claim an independent-contract sample.
