# Football historical validation

Evidence & results → Backtests exposes the existing public, reproducible historical diagnostics. It is a separate view from frozen pregame Results and GOING Picks cohorts. Historical projection error is useful evidence for rejecting weak ideas or registering a new Challenger; it does not automatically validate a betting edge, raise confidence or promote a model.

## Published tests

- Game scores: `scripts/backtest_nfl_context.py::walk_forward`, expanding season/week folds with at least 64 prior games, training kickoff +12h before the earliest test kickoff. Baseline and opponent-adjusted experiment are compared on the same games. RMSE in points; 2,000 week-cluster bootstrap draws for paired error-reduction intervals. Display the published season range, game count, baseline/challenger errors and interval; unknown values remain unknown. This is not necessarily the current production 80/20 policy or a new untouched confirmation set.
- Receiving roles: `walk_forward_roles`, next-game prediction using earlier weekly data, learning a role-ahead adjustment only from already graded earlier weeks with a 100-player-game zero prior. MAE in yards and overlapping declared role groups. Retrospective actual participation selects evaluated players. A positive group residual alone does not validate an improved projection or a bounce-back bet.

Snapshots are `data/football_game_validation.json` and `data/football_role_validation.json`; these remain generated by the existing refresh path. The UI reads the existing public snapshot API, falls back to packaged validated summaries, independently reports unavailable sources and supports retry. It does not fetch football providers, fit/tune models, synthesize decisions or rewrite records. No new data ingestion/workflow/system.

## Interpretation

These use latest revised nflverse sources, not a vintage archive. Historic source publication times, injury decisions and genuine pregame quotes are not comprehensively recoverable. Historical prices/ROI and closing-price edge are unavailable, even if a payload accidentally supplies an ROI field. No fabricated -110 prices, reconstructed /100 winners or retrospective tier relabeling.

$100-stake Results use real frozen contract/price/result records and remain hypothetical returns on selections, not an executed bankroll. Prospective cohorts stay separate by recipe; v1 /5 cannot validate v2 /100. New rating hypotheses need separately preregistered cutoffs/folds/benchmarks/criteria and future untouched observations. Current policies/Champion/C1/C2/ABBEYS/Score/DFS and protected ranking journals are unchanged.

NCAA has no published historical backtest in this view; its genuine prospective game results remain available. Full multi-season player-prop and as-of injury/usage backtests require source archives before they can establish predictive validation. The new view shows evidence that exists and its limitations; it does not imply that every method is validated.
