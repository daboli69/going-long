## Concrete defects and repairs

### Workbook dependency and JSON imports

`index.html:14` loads external `xlsx@0.18.5`; `:2693` and `:2780` read uploaded
workbooks. Published advisories identify this version as affected by prototype
pollution and denial-of-service issues: [CVE-2023-30533](https://github.com/advisories/GHSA-4r6h-8v6p-xvw6)
and [CVE-2024-22363](https://github.com/advisories/GHSA-5pgg-2g8v-p4x9).
No exploitation against GOING was attempted or established. Earlier zero npm
advisories did not cover this separately loaded CDN dependency. Review a current
permitted free distribution, license and advisory coverage; pin/vendor it, load
only when needed, and limit upload size/rows. Preserve the local-only workbook flow.

`shared/dfs-field.js:13` accepts an incomplete Showdown JSON with empty CPT/FLEX
tables; `:28` then throws during annotation. Root reproduction returned `ok:true`
before the TypeError. Validate tables/bins, totals, finite values, probability
bounds, feature names and coefficient/mean/SD dimensions before replacing the
last good model. Review Classic's optional calibration validator too
(`shared/dfs-classic-field.js:41`). Acceptance includes corrupt JSON, empty tables,
zero SD, NaN/Infinity and mismatched arrays, plus a valid synthetic model.
